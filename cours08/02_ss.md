# ss

`ss` (socket statistics) permet d'inspecter les connexions et les ports ouverts sur un système Linux.
Dans un contexte d'audit, `ss` permet d'identifier rapidement quels processus sont actifs sur le réseau.

## Quelques exemples

```bash
# Les sockets TCP et UDP en écoute
ss -tuln

# Lister aussi le pid du processus
sudo ss -tulpn

# Vérifier un port précis 
ss -tlpn | grep ":22"
```
